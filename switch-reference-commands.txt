Cisco Catalyst 3560 - Reference Commands
=========================================

WARNING:
These are documentation snippets based on the October 25, 2026 lab notes.
They are NOT a complete running configuration and should not be pasted blindly.
Check the current switch configuration, IOS support, interface roles, and maintenance
impact before making changes. Save a backup before editing.

Layer 3 routing
---------------
ip routing

DHCP relay (documented on VLAN 30, 40, and 50)
----------------------------------------------
interface vlan 30
 ip helper-address 192.168.10.10
!
interface vlan 40
 ip helper-address 192.168.10.10
!
interface vlan 50
 ip helper-address 192.168.10.10
!

DHCP snooping
-------------
ip dhcp snooping
ip dhcp snooping vlan 20,30,40,50
no ip dhcp snooping information option

interface gigabitEthernet0/1
 ip dhcp snooping trust
!
! Rate limiting of 15 was documented on access ports.
! Verify the exact interface configuration before applying:
! ip dhcp snooping limit rate 15

DHCP snooping database
----------------------
ip dhcp snooping database flash:snoop.db

Dynamic ARP Inspection (documented VLANs 30, 40, 50)
----------------------------------------------------
ip arp inspection vlan 30,40,50

interface gigabitEthernet0/1
 ip arp inspection trust
!

Port security (documented intent for Gi0/1 through Gi0/8)
---------------------------------------------------------
! Verify whether each interface is an access port and whether it connects
! to a server, endpoint, or another network device before applying.
switchport port-security
switchport port-security maximum 2
switchport port-security mac-address sticky

copy running-config startup-config
